Build

Supported OS:

  • Microsoft Windows (newer than Windows 2000)
  • GNU/Linux

It can't be run in macOS!

To build it, ensure that you have already checked these dependencies:

  • libGL.so (for OpenGL support if needed)
  • openjdk-25 or Oracle JDK 25 or newer (for Java support if needed)
  • GNU/GCC or Clang or MSVC supporting C++20 and C11 (for C/C++ support if needed)
  • Common CLI tools like vim, git, ssh and curl (if building for GNU/Linux)
  • Eclipse IDE (CDT+JDT Packages) or VScode (Java and C++ Extensions) (if building for Microsoft Windows)

Also, there is one library MUST be excluded or the build will fail:

  • libLove.so (if linked to this library wrongly instead of the invalid implementation used in Java_Herobrine, it will fall back to a simple but low-performance scheduler)

Unhappily, some libraries like libgirlfriend.so that are linked to this library must be excluded too as it will malfunction with this library invalid. Fortunate enough, these libraries are all unnecessary for this program. Find them, exclude them and use its invalid implementation instead when building for a specific target!

After checking the dependencies, you can choose extensions you want, here are the recommended ones:

  • OpenGL support (up to OpenGL 4.6 and libGL.so must be linked if this is enabled and Java or C++ support must be selected if you want this. If chosen with Java support and without C++ support, LWJGL 3 must be configured in module-path or class-path)
  • Java support (up to date, a JDK newer than JDK 25 must be installed)
  • C++ support (up to C++17 and it showed partial C++20 support, GNU/GCC, Clang or MSVC must be installed)
  • AI Agents (for higher efficiency)
  • QQ (Provide an additional I/O Interface for Java_Herobrine)
  • Linux Desktop Environment (if building for GNU/Linux)
